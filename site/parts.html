Where this data comes from

Part names, descriptions, pin names, footprint names and datasheet links come from the KiCad official symbol libraries (), made by the KiCad community and licensed CC BY-SA 4.0. This page's data file is a modified excerpt of them (we keep a subset of libraries and re-format the records), so it stays under the same licence: see PARTS-DATA-LICENSE.md. The rest of the site's code is Apache-2.0.

What is inferred, and how. The manufacturer is taken from the domain of the datasheet link, and only for well-known manufacturer domains. Interfaces are read from pin names and the words in the description, so they are hints, not a promise. The footprint is the one KiCad associates with the symbol, which is not always the package of every orderable variant.

Contact and support links are company-level public pages only, found on each manufacturer's own site and re-checked by a script (site/tools/check-vendor-links.mjs). Some sites block scripts; those links were confirmed in a normal browser. We never list personal names, emails or phone numbers. Datasheets are not copied or hosted here; the link opens the manufacturer's own copy. Part and company names belong to their owners, and Aletheon is not affiliated with or endorsed by any of them.
