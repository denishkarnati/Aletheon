# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org/); while the version is 0.x, minor
releases may change behaviour.

## [Unreleased]

### Added
- Worked examples in `examples/` (RP2040 UART driver, STM32F401 GPIO, nRF52840 UARTE, ESP32-S3 GPIO), generated by `npm run examples`
  from real vendor files. Each one has a step-by-step transcript and its evidence ledger.
- `npm run evidence`: runs every suite and writes `evidence/REPORT.md` with raw logs and their SHA-256 hashes. Local paths are scrubbed
  from the logs.
- Offline unit tests (`npm run test:unit`, 42 checks) for the SVD parser, the CMSIS-Pack reader, the header generator, argument safety
  and provider backoff. They are now part of `npm test`.
- Header compile check now also cross-compiles the RP2040, STM32F401 and nRF52840 headers for their Cortex-M CPUs.
- `docs/HANDBOOK.md`: usage by role, how to read the evidence, tool reference, hardware-in-the-loop guide, contributor guide.

### Fixed
- Windows: a build, flash or serial command that hit its timeout left the real tool running, because only `cmd.exe` was killed. The
  whole process tree is now killed.
- Windows: `%` is now rejected in toolchain arguments, because `cmd.exe` expands `%VAR%`.
- Node 24 `DEP0190` warning when spawning commands on Windows.
- AI provider calls now retry on 429, 529 and transient 5xx responses with backoff, honouring `retry-after`, instead of ending the agent run.

## [0.1.0]

First alpha: VS Code extension and MCP server; evidence ledger with trust classes; SVD and CMSIS-Pack register maps; datasheet search;
claim audit; SVD vs datasheet cross-check; SVD-grounded header generation; grounding benchmark.
